<Info>
  **Requisitos**:
  - Node.js 19 o superior
  - Un repositorio con un archivo `docs.json`
</Info>

Sigue estos pasos para instalar y ejecutar Mintlify en tu sistema.

<Steps>
<Step title="Instalar Mintlify CLI">

```bash
npm i -g mint
```
</Step>

<Step title="Previsualizar en local">

Navega a la carpeta de docs donde está tu `docs.json` y ejecuta:

```bash
mint dev
```

La vista previa local estará disponible en `http://localhost:3000`.

</Step>
</Steps>

## Puertos personalizados

Por defecto, Mintlify usa el puerto 3000. Puedes cambiarlo con `--port`. Por ejemplo, para usar el 3333:

```bash
mint dev --port 3333
```

Si el puerto está ocupado, usará el siguiente disponible:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Versiones de Mintlify

Cada release del CLI se asocia a una versión de Mintlify. Si la vista local no coincide con producción, actualiza el CLI:

```bash
npm mint update
```

## Validación de links

El CLI permite validar enlaces. Para detectar links rotos:

```bash
mint broken-links
```

## Troubleshooting

<AccordionGroup>
  <Accordion title='Error: Could not load the "sharp" module using the darwin-arm64 runtime'>

    Esto puede deberse a una versión antigua de Node. Prueba lo siguiente:
    1. Elimina el CLI actual: `npm remove -g mint`
    2. Actualiza a Node v19 o superior.
    3. Reinstala el CLI: `npm i -g mint`
  </Accordion>

  <Accordion title="Issue: Encountering an unknown error">
  
    Solución: elimina la carpeta `~/.mintlify` y ejecuta `mint dev` nuevamente.
  </Accordion>
</AccordionGroup>

¿Quieres ver cambios recientes del CLI? Revisa el [changelog](https://www.npmjs.com/package/mintlify?activeTab=versions).

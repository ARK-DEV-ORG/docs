## Comienza en tres pasos

Levanta tu sitio de documentación en local y aplica tu primera personalización.

### Paso 1: Configura tu entorno local

<AccordionGroup>
  <Accordion icon="copy" title="Clona tu repositorio de docs">
    En el onboarding creaste un repositorio con el contenido de tus docs. Puedes ver el enlace en tu [dashboard](https://dashboard.mintlify.com).
    
    Para clonar el repositorio y previsualizar cambios, sigue la guía de GitHub sobre [Clonar un repositorio](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository).
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Inicia el servidor de preview">
    1. Instala el CLI de Mintlify: `npm i -g mint`
    2. Entra a tu carpeta de docs y ejecuta: `mint dev`
    3. Abre `http://localhost:3000` para ver tus docs
    
    <Tip>El preview se actualiza automáticamente al editar.</Tip>
  </Accordion>
</AccordionGroup>

### Paso 2: Despliega tus cambios

<AccordionGroup>
  <Accordion icon="github" title="Instala la app de GitHub">
    Instala la app de GitHub de Mintlify desde tu [dashboard](https://dashboard.mintlify.com/settings/organization/github-app).
    
    La app despliega automáticamente tus cambios en producción.
</Accordion>
<Accordion icon="palette" title="Actualiza nombre y colores">
    Para un primer cambio, edita el nombre y los colores de tu sitio.

    1. Abre `docs.json` en tu editor.
    2. Cambia el campo `"name"` al nombre del proyecto.
    3. Actualiza `"colors"` para que coincida con tu marca.
    4. Guarda y revisa los cambios en `http://localhost:3000`.

    <Tip>Try changing the primary color to see an immediate difference!</Tip>
  </Accordion>
</AccordionGroup>

### Paso 3: Publica

<Accordion icon="rocket" title="Publish your docs">
  1. Haz commit y push de tus cambios.
  2. Tus docs se publicarán en minutos.
</Accordion>

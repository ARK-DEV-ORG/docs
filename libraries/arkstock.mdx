## Proyecto Open Source

**ARKSTOCK** es un sistema moderno de inventario y punto de venta (POS) diseñado para micro y pequeñas empresas. Es Open Source, se ejecuta 100% en local y permite instalar, revisar y auditar el código sin depender de servicios en la nube.

## Funcionalidades principales

- **Panel de control** con KPIs, gráficos en tiempo real y accesos directos.
- **Punto de venta (POS)** con búsqueda inteligente, descuentos globales y múltiples métodos de pago.
- **Gestión de inventario** con alertas de stock bajo y registro de ajustes.
- **Clientes y proveedores** con historial de compras y contacto.
- **Caja y finanzas** con arqueo y reportes PDF.

## Instalación

1. Descarga el ZIP del último release.
2. Extrae el contenido en una carpeta local.
3. Ejecuta `run_setup.bat`.
4. Busca ARKSTOCK en el menú de inicio.

## Requisitos mínimos

- Windows 10 (1809+) o Windows 11
- 2 GB de RAM
- 300 MB de espacio libre

## Stack tecnológico

- **.NET 8** y **WinUI 3**
- **C#**
- **SQL Server LocalDB**
- **QuestPDF** para reportes

## Seguridad y auditoría

- Sin telemetría oculta.
- Sin conexión obligatoria a internet.
- Base de datos local para clientes, ventas e inventario.
